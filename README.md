## 🟢 Lab 01: Network Traffic Analysis (Wireshark)

### 1. TCP 3-Way Handshake
![TCP Handshake](1.%20TCP%203-Way%20Handshake.PNG)

**Overview:**
This lab shows how two computers connect using three steps: **SYN**, **SYN-ACK**, and **ACK**. 
- **SOC Importance:** Analysts check this to find connection errors or detect "SYN Flood" attacks.

---

### 2. DNS Analysis
![DNS Analysis](2.%20DNS%20Analysis.PNG)

**Overview:**
DNS changes website names (like facebook.com) into IP addresses. 
- **SOC Importance:** It helps identify if a computer is trying to talk to a dangerous or malicious website.

---

### 3. HTTP Inspection
![HTTP Analysis](3.%20HTTP%20Analysis.PNG)

**Overview:**
HTTP is unencrypted, meaning the data is sent in "plain text". In this lab, we can see the exact details of the user's web request.
- **SOC Importance:** We monitor this to make sure sensitive data like passwords are not being sent without encryption.
